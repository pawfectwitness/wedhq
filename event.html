Trial Run

你對婚禮有意見、有迷思、有問題、有答案、有故事想分享，甚至純粹想入嚟八卦下，都歡迎。今次係 Trial Run，我哋想試下「匿名上線，一班人圍埋傾婚禮」究竟有冇人想玩。

HOW IT WORKS

兩個鐘係開門時間，唔係你要留低嘅時間。

圍爐唔係一場需要由頭坐到尾嘅 online event。喺指定嘅兩個鐘時段入面，WedHQ 會一直開住個 Google Meet room。你可以開門就入嚟，亦可以遲啲先出現；想留十五分鐘、半個鐘、一個鐘，或者由頭坐到尾都得。

入到嚟，想講就講，想聽就聽。要走嘅時候亦唔需要等「完場」。有人加入、有人離開，話題自然行落去。

你唔需要準備 topic，亦唔需要自我介紹。 Kit 同 Kevin 會準備一啲婚禮情景，有需要就拎出嚟開話題；如果現場自然傾到其他嘢，就由大家一路傾落去。

今次會係不留名圍爐。正式開放 RSVP 時，只需要留低一個 Alias，唔需要真名、公司名或者職位。活動日期同 RSVP 仲未開放；如果你有興趣，可以先喺下面留低 email，準備好第一次 Trial Run 時我哋會通知你。

BEFORE WE START

圍爐有幾個簡單默契

每一次圍爐，我哋都希望建基於互相尊重同誠信。大家願意抽時間入嚟，亦願意放心講嘢，先至會有真正值得傾嘅討論。以下幾樣唔係為咗防備大家，而係因為我哋珍惜呢段可以暢所欲言嘅時間。

唔起底。

你可以用暱稱、唔開鏡頭。如果認得或者估到其他參加者係邊個，就由佢繼續保持匿名。唔好查證，亦唔好向其他人透露。

圍爐入面嘅內容，留返喺圍爐。

唔錄音、唔錄影、唔截圖，亦唔將其他參加者分享過嘅內容帶到活動以外討論。

討論件事，唔係討論邊個。

大家可以有完全唔同嘅睇法。我哋想傾嘅係情景、問題同觀點，而唔係追查故事入面嘅人物。

公開之前，會先去除可辨識資料。

WedHQ 可能會將值得延伸嘅議題整理成日後《婚禮情景》，但會先移除或改寫可以辨識人物、時間、地點或事件嘅資料。

第一次做得到，先會有第二次。希望每一個嚟圍爐嘅人，都一齊尊重呢份默契。
